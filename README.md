**__Projet Web Front-End - HTML/CSS__**
Projet réalisé dans un cadre académique en 1ère année en groupe (3 personnes).
**Langage utilisés :** HTML5, CSS3
**Thème du site :** Site d'informations dédié à l'univers des montres de luxe
_______________________________________________________________________________
**Objectif :** concevoir un site web statique afin d’apprendre les bases du front-end
**Contribution personnelle :**
	- la conception globale du design du site (choix graphiques et structure)
	- l’intégration complète de la page d’accueil
	- le lien et l’intégration des pages développées par les autres membres du groupe
